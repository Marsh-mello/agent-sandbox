# 电脑端登录页原型

一个可直接在浏览器打开的桌面端登录页原型：左侧是字库样张与朱笔批注，右侧是登录表单。
纯静态 HTML + CSS + 原生 JS，无构建、无依赖、无外部字体，双击 `index.html` 即可查看。

## 查看

```sh
open login-prototype/index.html          # macOS
xdg-open login-prototype/index.html      # Linux
```

或起一个静态服务器（推荐，避免个别浏览器对 `file://` 的限制）：

```sh
python3 -m http.server 8000
# 然后访问 http://localhost:8000/login-prototype/
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：样张区 + 登录表单 |
| `styles.css` | 全部样式与设计令牌（颜色、字体、间距） |
| `app.js` | 表单校验、密码可见性、模拟提交 |
| `docs/DESIGN.md` | 设计说明：配色、字体、版式与取舍 |
| `docs/screens/*.png` | 改动前后对照、各状态与各分辨率截图 |

## 已实现

- 邮箱与密码必填校验，失焦即校验，出错时就近说明并聚焦到该字段。
- 密码可见性切换（`aria-pressed`，读屏可播报状态）。
- 「保持登录 30 天」复选框。
- 提交后的加载态与模拟结果提示，可「重新演示」重置。
- 完整键盘操作、可见焦点环、`aria-live` 状态播报、`prefers-reduced-motion` 支持。
- 1440 / 1920 / 1366 / 1100 / 1024 / 820 宽度下无横向溢出。

## 范围说明

- 这是**界面原型**：不连接任何后端，不校验真实账号，不发起网络请求。
- 目标是桌面浏览器；窄屏会退化为单栏并保持可用，但未针对移动端设计。
- 文案、品牌名（合文铸字所）与样张内容均为原型占位内容。
