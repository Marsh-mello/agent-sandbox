# 登录页原型 · 设计说明

本文件记录原型的设计取向与取舍，方便评审时判断「为什么长这样」，
而不是把页面当成既定的产品设计。原型只演示一个电脑端登录界面的形态，
不连接真实后端，不包含任何真实账号。

## 一句话

一页正在被审阅的样张：左侧是字库样张与朱笔批注，右侧是笔直、安静的登录表单。
情绪全部留在样张里，操作区只负责清楚。

## 目标与边界

- 目标设备：电脑浏览器，主场景 1440×900；1280 以上保持左右分栏，1120 以下
  样张竖排，780 以下退化为单栏。
- 界面语言：简体中文，英文只出现在品牌英文名与 SSO 缩写里。
- 范围：静态原型（HTML + CSS + 原生 JS），双击即可打开，也可静态托管。
- 不做：真实鉴权、接口调用、路由跳转、账号体系、后端。

## 设计计划

### 颜色

纸与墨：整个页面是一张纸，不是一块屏幕。

- `--paper: #e7e6de` 左栏样张纸（略暗）
- `--paper-hi: #f5f4ee` 右栏表单纸（略亮一档，把注意力交给操作区）
- `--ink: #15160f` 墨黑：正文、主按钮底
- `--ink-80 / --ink-60 / --ink-40`：`#3c3d34 / #5f6055 / #6e6f62` 三级次级文字，
  最浅的一级对纸底仍有 4.6:1，用作占位符与脚注
- `--rule / --rule-soft`：`#b9b8aa / #cdccc0` 只做分隔线，不承担文字

印刷色两种，各司其职：

- `--indigo: #2b4c9b` 靛：焦点环、已选状态、链接悬停
- `--seal: #a6342a` 朱：印章、批注、错误提示

朱色只出现在「有人在纸上写字」的地方（印章、朱批、错误），靛色只出现在
「界面在回应你」的地方（焦点、悬停）。两者不混用，看颜色就知道发生了什么。

### 字体

- 正文与界面：`"Noto Sans CJK SC", "Source Han Sans SC", "PingFang SC"…`。
  正文 14.5–16px，行高 1.7；中文不用细体，最小 11px 只用于脚注。
- 展示字：`"Noto Serif CJK SC", "Songti SC", serif`，只用于品牌名、页面标题、
  样张字与朱批正文。宋体出现在「印刷物」上，表单控件仍是无衬线。
- 不引第三方字体，全部走系统字体栈，离线打开也不会掉字或闪烁。

### 版式

左栏约 57%，右栏约 43%，中间一条 1px 墨线。左右两栏内容各自左对齐，
表单固定 380px 宽并垂直居中；左栏内容限宽 760px 居中，避免 1920 宽度下
样张被拉得过散。

### 原则

1. 左栏讲「这家公司做什么」，右栏只做「登录」。左栏可以有一枚印章、一处朱批、
   一张字格；右栏除了字段、按钮和必要的说明，不加任何装饰。
2. 层级靠字重、间距和一条细线，不靠卡片阴影、圆角胶囊或渐变。全站只有两个
   圆角值：输入框与按钮 2px，印章 1px。
3. 状态必须看得见：焦点是靛色 2px 环，错误是朱色描边加浅底加就近说明，
   成功是靛色文字；键盘 Tab 顺序与视觉顺序一致。
4. 文案说人话：按钮写「登录」，加载时写「正在登录」；错误说明发生了什么，
   例如「邮箱格式看起来不完整，例如 name@studio.cn。」，不写「操作失败」。

## 已实现的交互

- 邮箱、密码必填校验；邮箱另校验格式。失焦校验，出错时就近提示并把焦点
  移到第一个出错的字段。
- 密码可见性切换：`aria-pressed` + 文案在「显示 / 隐藏」间切换。
- 「保持登录 30 天」复选框。
- 提交后按钮进入加载态（`aria-busy`），1.2 秒后给出模拟结果，并提供
  「重新演示」把表单重置回初始状态。
- 状态提示放在 `role="status"` 的 `aria-live="polite"` 区域里，读屏可播报。
- 完整键盘可用：Tab / Shift+Tab、Enter 提交、Space 切换复选框。
- `prefers-reduced-motion: reduce` 时关闭过渡与加载动画。

## 已知取舍

- 登录不校验密码复杂度，只确认非空：复杂度规则属于注册与找回密码，放在
  登录页会泄露规则并且对已有账号不成立。
- 「忘记密码」「申请试用」「服务条款」等是原型内的占位链接，不跳转。
- 「使用企业 SSO 登录」只演示按钮层级，点击后给出说明性提示。
